### 3.2 핵심 마커 (drift 감지용)

1. `CHARTER_CHECK: auto-generated by OMA spawn-status` (가장 유일, 충돌 0)
2. `antigravity stdout` (Antigravity headless 캡처 분기 식별)

둘 다 글로벌 cli.js에 존재해야 청사진 클린 판정.

### 3.3 upgrade.sh 흐름 (8 step)

1. 사전 검증 (OMA src git repo · bun · git · sha256sum)
2. 글로벌 cli.js 백업 → `backups/oma-upgrade-{timestamp}/`
3. `git stash --include-untracked` → working state 완전 보존
4. `git fetch origin main` → `git pull --rebase origin main`
5. `git stash pop` → 우리 수정 reapply (conflict 시 즉시 정지·사용자 알림·롤백 안내)
6. `bun run typecheck` + `bun run build`
7. Deploy: `cp cli/bin/cli.js $GLOBAL_CLI`
8. Drift verify + (선택) Spawn verify (`-m antigravity` ~$0.02)

옵션:
- `--check-only` — drift 감지만, 업그레이드 없음
- `--skip-spawn` — spawn 검증 단계 건너뜀
