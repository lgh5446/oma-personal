## 7. 자동 검증 흐름 (이제부터 작동)

```
사용자 변경 → git commit → git push
    ↓
GitHub Actions 자동 트리거 (3 jobs 병렬)
    ↓
3-5분 후 결과:
  ✓ 녹색 → README 배지 ✅ 유지, 안심
  ✗ 빨간색 → PR 차단 + email 알림 → 사용자가 수정 후 재push
```

매 push마다 회귀 자동 감지. 사용자가 무심코 SSOT 깨뜨려도 즉시 알림.
